Lets a local tool drive the live op. Opens a loopback socket on port 48291 that requires the pairing key below — it grants access to this HUD, never to your org account, and every action is still checked by the server. Takes effect on restart.
Lets keyboard/hardware play, pause, next and previous drive the op's music bed through Windows. Only active while you lead a live op with an audible bed, and it shares the media keys with other players — Windows decides which one a press reaches.

Size is the same control as dragging a widget's corner — both scale the widget and its contents together. Drag an edge to change the box instead.

Sets which widgets are shown. Your sizes and positions are kept, and you can change anything afterwards.
Click a combo to rebind it. Needs Ctrl or Alt; use the left-hand ones.
EscBack to pass-through display from either mode, in one press (so does the Done ✕ button and every tray item). Never rebindable — it is the escape hatch the hotkeys are allowed to fail without.
DragMove any widget while interacting. Reset layout puts them all back.
Drag an edgeResize a widget's box — the contents reflow into it. Height stays automatic until you drag a top or bottom edge.
Drag a cornerScale the widget and everything in it. Same control as that widget's Size slider on the Widgets tab; the opposite corner stays put.
No hotkey is swallowed — the combo still reaches the game.
